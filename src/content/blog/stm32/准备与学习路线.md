> 这个系列基于 2026 年 11 月 Arch Linux 官方仓库里的软件版本编写。我写作时还没有在真实开发板上逐条跑过文中的命令，步骤整理自 ST 官方文档、ArchWiki、OpenOCD 文档和各工具的说明。如果你遇到文中没写到的情况，欢迎反馈。

很多人学单片机的第一步是装 Keil，然后照着视频点灯。这条路没问题，但如果你和我一样：**主力系统是 Linux、想借单片机把 C 语言学扎实、不想被一个 IDE 挡住视线**，那全程在 Linux 上学是一个很好的选择。

这一章不写代码，先把"学什么、买什么、用什么工具、按什么顺序学"讲清楚。

## 一、为什么是 STM32F103

单片机种类很多：51、AVR（Arduino）、STM32、ESP32、RP2040……对一个**想练 C 语言**的新手，我推荐 STM32F103C8T6，理由是：

1. **资料最多**：国内的入门教程、开源项目、论坛问答，绝大多数都围绕 F103 展开，遇到问题基本都能搜到答案。
2. **最能练 C**：STM32 的程序里到处是指针、结构体、位运算、`volatile`、宏定义。比如"把 GPIOC 的第 13 位置 1"这种操作，本质就是对一个内存地址做位运算。在 Arduino 上这些都被封装掉了，在 STM32 上你每天都会用到。
3. **用途广**：PWM、ADC、定时器、各种通信接口都有，电机控制、电源、数据采集、竞赛项目都用得上。学会以后迁移到 GD32 等国产兼容芯片，或者更高端的 STM32 型号，都很快。
4. **便宜**：最小系统板十几二十块钱，下载器也是二十块左右。

型号里的字母和数字代表什么，了解一下就行：

| 部分 | 含义 |
|---|---|
| STM32 | ST 公司的 32 位单片机 |
| F1 | 基础型系列，内核是 ARM Cortex-M3 |
| 03 | 增强型 |
| C | 48 个引脚 |
| 8 | 64 KB Flash（程序存储） |
| T | LQFP 封装 |
| 6 | 工作温度 -40～85 ℃ |

它的 RAM 是 20 KB，主频最高 72 MHz，后面写链接脚本、配置时钟的时候会用到这几个数字。

## 二、为什么全程用 Linux

江科大等主流教程都用 Windows + Keil。Keil 很好用，但它把很多东西藏在了界面后面：点一下"编译"，你不知道它调用了什么编译器、传了什么参数；点一下"下载"，你不知道程序是怎么写进芯片的。

在 Linux 上，每一步都是一条你看得见的命令：

| 步骤 | Keil 里 | 本系列用的工具 |
|---|---|---|
| 写代码 | Keil 编辑器 | **Vim**（配 clangd 补全和跳转） |
| 编译 | 点"Build" | **arm-none-eabi-gcc**，由 **Makefile** 组织 |
| 链接 | 自动处理 | **链接脚本**（`.ld`），自己写 |
| 下载 | 点"Download" | **OpenOCD** + ST-Link |
| 调试 | Keil 调试界面 | **arm-none-eabi-gdb** + Vim 自带的 **termdebug** |
| 串口助手 | 各种 Windows 串口软件 | **picocom** |

这些工具全部开源、免费，Arch 官方仓库一条命令就能装好。更重要的是，学会这一套以后，你对"一份 C 代码是怎么变成芯片里跑的程序"会有完整的认识，这对学 C 语言本身也很有帮助。

> 如果你更喜欢图形界面，ST 官方的 **STM32CubeIDE** 也有 Linux 版（AUR 上的 `stm32cubeide`）。但它默认用 HAL 库，和江科大的标准库教程对不上，这个系列不用它。

## 三、标准库还是 HAL 库

ST 给 STM32 提供过几种官方库，新手最常听到的是两种：

- **标准库**（Standard Peripheral Library）：老一些，F1 系列已经停止更新，但结构简单，函数名直白（比如 `GPIO_Init`、`GPIO_SetBits`），读源码就能看懂它对寄存器做了什么。江科大的入门课用的就是它。
- **HAL 库**：ST 现在主推的库，配合 STM32CubeMX 图形化生成代码，适合做项目，但封装层次多，初学时不容易看清底层。

这个系列**用标准库**，原因是能和江科大的视频一一对应：你在视频里看原理和代码，回到 Linux 上照着写，唯一的区别是编译和下载的方式。等基础打好了，再学 HAL 库会很快。

## 四、购物清单

### 1. 必须买的

| 物品 | 说明 | 参考价 |
|---|---|---|
| STM32F103C8T6 最小系统板 | 常见的蓝色小板，板载 PC13 LED 和 8 MHz 晶振 | 15～25 元 |
| ST-Link V2 下载器 | 用来烧录和调试，买便宜的仿制版就行 | 15～20 元 |
| USB 转 TTL 模块（CH340） | 串口通信用，第 6 章要用 | 5～10 元 |
| 面包板 + 杜邦线 | 公对公、公对母、母对母各来一些 | 15～20 元 |
| LED、电阻、按键 | 基础实验用，电阻买 220 Ω～1 kΩ 的就够 | 5～10 元 |

### 2. 跟着江科大学还要买的

江科大的课程后面会用到这些模块，可以一次买齐，也可以学到再买：

- 0.96 寸 OLED 显示屏（4 针 I2C 版）——几乎每一节课都用它显示结果，**建议第一批就买**
- 蜂鸣器模块、光敏电阻模块、热敏电阻模块、对射式红外传感器
- 旋转编码器、电位器
- 舵机（SG90）、直流电机 + TB6612 电机驱动模块
- MPU6050 陀螺仪模块、W25Q64 Flash 模块

### 3. 挑套件的注意事项

淘宝上有很多"STM32 入门套件"，挑的时候注意：

1. **对照课程的器材清单看**：不少通用套件里放的是数码管、点阵屏这些课程用不到的东西，反而缺按键、电位器、OLED、电机驱动等课程里要用的。直接搜"江科大 STM32 套件"能找到按课程配好的。
2. **芯片可能是兼容片**：标着"进口芯片"不一定是 ST 原厂，也可能是 CKS32、APM32 这些国产兼容芯片。学习完全够用，只是烧录时可能要多加一个参数（第 4 章会讲）。拿到板子后看看芯片上的丝印就知道了。
3. **ST-Link 要带 SWDIO、SWCLK 引脚**：常见的 U 盘造型 ST-Link V2 都有，侧面印着引脚定义。
4. **线够用**：杜邦线公对母、母对母都要有，最小系统板插在面包板上以后，连 ST-Link 和 CH340 都要用到。

## 五、学习路线

### 1. 先在电脑上学 C（2～4 周）

先不要急着买板子。单片机程序出了问题，可能是代码、接线、芯片、工具链中任何一个环节，新手很难定位。**先在电脑上把 C 语言的基础打牢**，到了板子上就只需要关心硬件相关的部分。

在 Arch 上装好编译器和调试器就可以开始：

```bash
sudo pacman -S gcc gdb make
```

写一个 `hello.c`：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, STM32!\n");
    return 0;
}
```

编译运行：

```bash
gcc -Wall -g hello.c -o hello   # -Wall：打开常见警告；-g：带上调试信息
./hello
```

这个阶段的重点：

- 变量、类型、循环、函数、数组——基础语法
- **指针**——单片机里访问寄存器全靠它
- **结构体**——标准库的初始化全是"填结构体、传指针"
- **位运算**（`& | ^ ~ << >>`）——置位、清零、取某一位
- **宏定义**和 `#include`——标准库里大量使用
- 会用 `gdb` 单步执行、看变量——到板子上调试时用的是同一套命令

教材推荐《C Primer Plus》，视频推荐 B 站翁恺的 C 语言课程。Vim 的基本用法可以看本站的[《Linux 命令行基础保姆级教程》](/series/archlinux/linux基础教程/)里的 vim 入门部分。

### 2. 搭环境、跑通第一个程序（本系列第 2～6 章）

板子到手后，按本系列的顺序：

1. 第 2 章：装工具链，把 Vim 配成能补全、能跳转的 C 编辑器
2. 第 3 章：搭一个标准库工程，理解启动文件、链接脚本和 Makefile
3. 第 4 章：点亮板载 LED，用 OpenOCD 烧录
4. 第 5 章：用 GDB 单步调试，直接看寄存器
5. 第 6 章：串口通信，把 `printf` 输出到电脑上

走完这几章，你就有了一套完全不依赖 Keil 的开发环境。

### 3. 跟着江科大学外设

之后就可以跟着江科大的视频学 GPIO、中断、定时器、PWM、ADC、DMA、USART、I2C、SPI 了。视频里关于 Keil 的操作（新建工程、配置选项、点下载）都可以跳过，换成本系列的方法：

| 视频里 | 你在 Linux 上 |
|---|---|
| 新建工程、添加文件 | 把 `.c` / `.h` 放进对应目录，Makefile 自动找到 |
| 点"编译" | `:make` |
| 点"下载" | `:make flash` |
| 串口助手 | `picocom` |

后续我也会按这个顺序更新外设章节。

## 六、本章小结

- 芯片选 **STM32F103C8T6**，库用**标准库**，跟着**江科大**的视频学原理
- 工具链：**Vim + arm-none-eabi-gcc + Makefile + OpenOCD + GDB + picocom**，全部来自 Arch 官方仓库
- 买东西：最小系统板 + ST-Link + CH340 + 面包板和线，OLED 建议第一批就买
- 顺序：**先在电脑上学 C → 搭环境点灯 → 跟着课程学外设**
