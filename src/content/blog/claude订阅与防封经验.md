## 一、具体流程

### 1. 网络环境的配置

这是最重要的环节，IP 的质量是决定性因素。尽管你可能在网上看到有人说自己用机场多久多久没有被封控balabala，但是据本人经验，拥有一个好的 IP 是至关重要的。

#### IP 如何购买

想必你已经有了机场节点，你只需要再去专门的 IP 代理商购买一个静态 IP。

需要说明的是，社区一般称这种静态 IP 为住宅 IP，实际上你很难买到真实的住宅 IP，绝大多数都是伪装的机房 IP。但是这不重要，机房标识不重要，重要的是纯净。

这通常要花费 3～10 美元每月不等，IP 质量在大多数情况下和价格成正比，但说不准你高价买到了一个很烂的，或者低价淘到满分 IP。

浏览器搜索关键词：住宅 IP、静态 IP、ISP。

#### 如何判断 IP 质量

| 网站 | 我主要查看的信息 |
| --- | --- |
| [IPPure](https://ippure.com) | IP 纯净度 |
| [Claude 检测页](https://ip.net.coffee/claude) | 第三方提供的 Claude 相关检测结果 |
| [IP 检测](https://ipjiance.com) | IP 这个评分尽量110以上 |
| [Scamalytics](https://scamalytics.com) | 欺诈值评分越低越好 |
| [IPIPLA](https://ipipla.com) | IP 归属、运营商与网络类型 |

综合以上检测网站，尽量挑选到一个优质 IP。

**其实这一步是最麻烦的，在漫天的垃圾ip中淘到一个能用的其实不太容易。不光费时间还费钱，有很多网站不提供试用，因此你不得不以十几或者几十块钱月付买下来再去测试。就算你在这家买到一个顶级ip，也不能保证这家所有ip都是优质的，所以红苹果并不能给大家推荐商家。**

#### 如何配置

在代理商网站你会拿到这些东西：

```text
IP
端口
用户名
密码
```

1. 打开你的 Clash 订阅页面。
2. 右键你想要的前置机场，点“编辑节点”，输入：

   ```text
   socks5://用户名:密码@IP:端口
   ```

3. 点“添加节点”。

**在 Clash 首页选择“全局”，然后开启“虚拟网卡模式”。**

4. 回到代理页面，点击右上角“链式代理”。
5. 选择前置节点，选择 SOCKS5 节点。
6. 点击“连接”。

**做完这些，按下win+R,输入`ncpa.cpl`,右键你的实际网卡，取消勾选ipv6选项，点击确定**

浏览器打开[检查配置网页](https://ip.net.coffee/claude/)，尽量把绿灯都点亮。

>有关dns泄露问题可借助codex/dsh解决；有关webrtc泄露，请在 Chrome 扩展商店，添加“WebRTC Control”。


### 2. 设备环境配置与 Gmail 注册

配置好网络，确定好出口 IP 之后，进行以下操作：

1. 打开 Chrome，点击右上角竖列的三个点，鼠标移到你的账号上，点击“添加新的个人资料”，点“Stay signed out”。进入新的浏览器页面，设置浏览语言为英语，删除中文，重启该浏览器页面。后面的登录操作都在该新资料页完成。
2. 不要忘了打开 Chrome 扩展商店，添加“WebRTC Control”。
3. 打开电脑设置，更改时区与地区，确保和 IP 出口所在地一致。
4. 浏览器打开[Google 账号注册页面](https://accounts.google.com/signup)，点击“创建账号”，选择“个人用途”。按照页面提示填写姓名、出生日期等信息，选择或创建 Gmail 地址，设置密码；如果出现手机号验证，按提示完成，然后确认条款，完成注册。
5. 注册好 Gmail 账号后，点击右上角头像，点“Manage your Google Account”，按要求添加辅助邮箱、电话号码。只要 IP 够干净，`+86` 也没问题。
6. 再点 Wallet，添加付款方式，添加你的银行卡。随便找个美国免税州地址生成器，填入账单地址。

### 3. Claude 注册登录

确保[Claude 检测页](https://ip.net.coffee/claude)全绿，`host` 属性无所谓，登录[Claude 官网](https://claude.ai)，选择 Google 登录。

恭喜你，成功注册 Claude 账号。

有关养号，虽然社区反馈不需要养号，但我认为还是应该等待至少 72 小时再充值，期间可以适当使用 Claude。

## 二、手机支付

**请务必在手机支付，不要尝试在网页端支付。**

安卓手机本人亲测可以通过 Google 支付。

苹果手机据社区反馈可以使用 App Store 礼品卡充值。

### 1. 配置手机网络环境

先配置好手机的网络环境。经由本人测试，手机代理软件没有“链式代理”选项，所以请你把节点配置文件和从代理商网站获得的 IP 信息交给 AI，让它重新生成一份配置文件，然后导入你手机的配置文件。

提示词为：

> 请将以下静态 IP 信息添加为配置中的 SOCKS5 节点，以“xx 节点”为前置，连接顺序为：本机 → 前置节点 → SOCKS5 节点 → 目标网站。使用客户端支持的语法，保留原有配置，将新节点加入代理组，并输出可直接导入的完整配置。

### 2. 登录 Google 账号

确保手机出口节点和电脑一致，打开全局模式，打开 Google 商店。

点击头像，点击“管理您的账号”，登录你刚在电脑注册的账号。

### 3. 安装 Claude 并订阅

同样更改手机时区，更改语言为英语，拔出 SIM 卡，在登录了上述账号的 Google 商店下载 Claude。

如果你此前下载过，请卸载重装。

打开 Claude，使用 Google 登录。点进 Claude 设置，升级套餐，选择 Pro，不要一上来就 Max，使用 Google 支付。

如果没有弹出“KYC 认证”或者封号的情况下，你的 Pro 就算是充值成功了。

之后你就可以登录你的 Claude 桌面版了。

**谨记：在整个注册、登录以及 Claude 的使用过程中，请不要跳变 IP，请不要在没有使用代理的情况下打开 `claude.ai` 或者 Claude Desktop。**
